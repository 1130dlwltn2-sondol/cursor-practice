# Cursor 실전 가이드

에디터 안에서 끝내는 AI 코딩을 처음부터 끝까지 다룬 실전서입니다.

Cursor는 VS Code를 기반으로 한 AI 코드 에디터입니다. Tab 자동완성이 다음 편집을 미리 예측하고, Chat은 코드베이스 전체를 이해한 상태에서 답하며, 에이전트 모드는 기능 하나를 통째로 만들어 테스트까지 돌립니다. 이 책은 설치와 첫 설정, VS Code 마이그레이션, Tab과 Chat, @ 멘션과 Composer, 에이전트 모드, 터미널 자동 실행, 디버깅과 테스트 자동화, Rules와 MCP 연동, 팀 도입과 요금제 관리까지 다룹니다.

마지막에는 Claude Code(터미널형)와의 비교로 상황에 맞는 도구를 고르는 기준을 정리하고, 에이전트 모드로 기능 하나를 통째로 만드는 실전 프로젝트와 확인 문제 20문항, 상세 해설을 수록했습니다.
