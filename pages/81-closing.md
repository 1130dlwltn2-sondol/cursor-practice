# 마무리

이 책에서는 Cursor를 처음 설치하는 단계부터 에이전트 모드로 기능을 통째로 만드는 흐름까지 다뤘다. Tab 자동완성으로 시작해 Chat과 코드베이스 이해를 거치고, 에이전트 모드, 터미널 승인, 디버깅과 테스트 자동화를 익혔다. Rules와 MCP, 팀 도입, 요금제 관리로 시야를 넓히고, Claude Code와의 비교로 선택 기준을 정리한 뒤, 실전 프로젝트 5단계로 모든 내용을 하나로 묶었다.

책을 덮기 전에 한 가지를 강조하고 싶다. Cursor를 포함한 AI 에이전트는 개발자를 대신하는 도구가 아니라, 개발자의 판단 속도를 올려주는 도구이다. 에이전트가 빠를수록 사람의 확인이 더 중요해진다. 범위를 정하고, 계획을 읽고, diff를 보고, 테스트로 검증하는 습관은 도구가 바뀌어도 그대로 통한다.

다음 단계로 해볼 만한 일을 정리한다.

- 개인 프로젝트 하나를 골라 에이전트 모드 5단계를 처음부터 끝까지 적용해 보자.
- 자주 반복하는 지시 세 가지를 .cursor/rules 파일로 옮겨보자.
- 읽기 전용 MCP 서버 하나를 등록해 문서 검색이나 DB 조회를 에이전트에게 맡겨보자.
- 한 달간 사용량을 측정해 보고 요금제와 모델 선택을 조정해 보자.
- 팀에서 쓴다면 파일럿 그룹을 만들어 규칙과 승인 정책을 문서화해 보자.

Cursor는 빠르게 바뀌는 도구이다. 이 책의 기준일은 2026년 10월이며, UI 명칭이나 단축키, 요금제가 달라졌을 수 있다. 정확한 최신 정보는 공식 문서(https://docs.cursor.com/)에서 확인하자.
