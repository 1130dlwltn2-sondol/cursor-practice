1. 정답: 1. 에이전트는 지시, 탐색, 계획, 실행, 검증을 순환하며 작업한다.

3. 정답: 2. 처음에는 매번 확인 모드로 에이전트의 명령 패턴을 파악한 뒤 자동 실행을 넓힌다.
4. 정답: 1. 에러 메시지 전문, 재현 방법, 관련 파일을 함께 주면 원인 파악이 빨라진다.
5. 정답: 2. 원인 분석을 먼저 확인하면 잘못된 수정을 막을 수 있다.
6. 정답: 2. 도메인 특유의 경계 케이스는 사람의 도메인 지식이 필요하므로 사람이 보완한다.
7. 정답: 2. 코드와 테스트 중 어느 쪽이 틀렸는지 판단한 뒤에 고쳐야 한다.
8. 정답: 2. .cursor/rules의 규칙은 저장소에 커밋되어 팀 전체에 공유된다.
9. 정답: 1. globs는 규칙이 적용될 파일 패턴을 지정한다.
10. 정답: 2. 읽기 전용부터 시작해 에이전트의 도구 호출 방식을 관찰하는 것이 안전하다.
11. 정답: 2. DB 연결은 조회만 가능한 읽기 전용 계정으로 시작한다.
12. 정답: 2. 소규모 파일럿으로 실제 업무에 적용해 본 뒤 확대한다.
13. 정답: 1. 규칙과 설정을 저장소에 넣으면 새 팀원도 클론만으로 같은 기준을 갖는다.
14. 정답: 2. Pro 플랜은 월 20달러이다.
15. 정답: 2. 연간 결제 시 20% 할인이 적용된다.
16. 정답: 2. 범위를 잘게 나누고 파일을 지정하면 탐색 비용이 줄어 크레딧을 아낄 수 있다.
17. 정답: 2. Cursor는 에디터형, Claude Code는 터미널형으로 일하는 장소가 가장 큰 차이이다.
18. 정답: 2. Cursor는 VS Code 계열 에디터를 그대로 쓰므로 확장과 설정을 이어 쓸 수 있다.
