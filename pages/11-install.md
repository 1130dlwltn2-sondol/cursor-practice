# Part 1. Cursor 시작하기

## 11. 설치와 첫 설정

Cursor는 운영체제별로 설치 파일을 제공한다. 공식 사이트에서 내려받아 실행하면 된다. 설치 과정 자체에는 어려운 부분이 없다. 몇 분이면 끝난다.

설치가 끝나고 처음 실행하면 로그인 화면이 나온다. 계정을 만들어 로그인하자. 로그인이 끝나면 기본 설정 단계로 넘어간다. 여기서 몇 가지를 미리 정해 두면 이후가 편하다.

첫째, 테마와 폰트다. VS Code를 쓰던 사람이라면 익숙한 테마를 그대로 쓰면 된다. 폰트는 코딩용 폰트를 쓰는 것이 좋은데, 이미 쓰고 있던 것이 있으면 그대로 가져오면 된다.

둘째, Tab 자동완성 켜기다. Cursor의 핵심 기능이므로 기본적으로 켜져 있는 경우가 많지만, 설정에서 상태를 확인해 두자. 설정 화면에서 Tab 관련 항목을 검색하면 자동완성의 켜짐 여부와 동작 방식을 조정할 수 있다. 정확한 메뉴 이름은 버전에 따라 바뀔 수 있으니, 찾지 못하면 설정 검색창에 tab이라고 입력해 보면 된다.

셋째, 코드베이스 인덱싱이다. 프로젝트 폴더를 처음 열면 Cursor가 코드베이스를 인덱싱하기 시작한다. 임베딩과 심볼 분석을 통해 파일들의 관계와 의미를 파악하는 과정이다. 이 인덱스가 있어야 Chat이 열지 않은 파일까지 참조해서 답할 수 있다. 인덱싱은 백그라운드에서 진행되며, 프로젝트 크기에 따라 시간이 걸린다. 처음에는 잠시 기다렸다가 진행하는 것이 좋다.

넷째, 단축키 확인이다. VS Code의 단축키와 대부분 호환되지만, Cursor 고유의 기능에는 Cursor 전용 단축키가 붙어 있다. 예를 들어 Chat 패널을 여는 단축키나 인라인 편집을 부르는 단축키가 있다. 자주 쓰는 것만 메모해 두고 시작하자.

간단한 실습을 해보자. 새 폴더를 하나 만들고, 그 안에 `hello.py` 파일을 만든다.

```python
def greet(name):
    return f"Hello, {name}!"
```

파일을 저장하고 몇 줄 더 타이핑해 보자. 예를 들어 `print(`까지만 쓰고 잠시 멈추면, 회색 텍스트로 자동완성 제안이 뜰 것이다. Tab을 눌러 수락해 보고, 다음에는 Esc를 눌러 취소해 보자. 이 감각이 Cursor 사용의 절반이다.

주의점도 있다. 인덱싱이 끝나지 않은 상태에서 Chat에게 "이 프로젝트 구조가 어떻게 돼?"라고 물으면 엉뚱한 답이 나올 수 있다. 인덱싱 상태를 확인하고, 끝나기를 기다렸다가 쓰는 습관을 들이자. 또 하나, 자동완성 제안이 항상 옳은 것은 아니다. 회색 텍스트를 무조건 Tab으로 받아들이면 이상한 코드가 들어갈 수 있으니, 한 번 읽고 수락하는 습관이 필요하다.

핵심 정리
- 운영체제별 설치 파일을 받아 설치하고, 첫 실행 시 로그인한다.
- Tab 자동완성 켜짐 여부와 코드베이스 인덱싱 상태를 먼저 확인한다.
- Cursor 고유 단축키는 자주 쓰는 것만 메모해 두고 시작한다.
